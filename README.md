# Phishing URL Detector

A machine learning model that classifies URLs as phishing or legitimate,
served via a Flask web app.

## What it does

Takes a URL as input and returns:
- A classification: **phishing** or **legitimate**
- A confidence score (0 to 1)

## Dataset

Two datasets merged into one:
- `phishing_dataset.csv` — labelled phishing URLs
- `url_dataset.csv` — labelled legitimate URLs

Combined size after deduplication: **490,921 URLs**
Class distribution: 438K legitimate vs 52K phishing (8:1 imbalance)

## Features extracted from each URL

| Feature | Description |
|---|---|
| `url_length` | Total character length |
| `dot_count` | Number of dots |
| `has_at` | Presence of @ symbol |
| `has_ip` | IP address used instead of domain |
| `hyphen_count` | Number of hyphens |
| `slash_count` | Number of forward slashes |
| `has_https` | 0 if HTTPS, 1 if HTTP |
| `digit_count` | Number of digits |
| `is_shortened` | Matches known URL shorteners |
| `domain_length` | Length of the domain portion |
| `subdomain_count` | Number of subdomains |
| `has_suspicious_words` | Contains keywords like login, verify, bank |
| `suspicious_tld` | Uses suspicious TLDs like .xyz, .tk, .ml |

## Model

Random Forest Classifier (scikit-learn)
- 200 estimators
- Max depth: 20
- `class_weight='balanced'` to handle class imbalance
- Train/test split: 80/20 with stratification

**Test set performance:**
- Overall accuracy: 92%
- Phishing precision: 60% / recall: 82%
- Legitimate precision: 98% / recall: 94%

## Known limitations

- Flags some legitimate short domains incorrectly (e.g. google.com)
- Does not use domain age or WHOIS data
- Trained on a static dataset — does not adapt to new phishing patterns
- Class imbalance affects phishing detection confidence

## Setup

```bash
git clone https://github.com/C4naryS0ck/cuddly-potato
cd cuddly-potato
pip install -r requirements.txt
```

Run the notebook first to generate `model.pkl`, then:

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.

## API

**POST** `/predict`

Request:
```json
{ "url": "https://example.com" }
```

Response:
```json
{
  "prediction": "phishing",
  "confidence": 0.76
}
```
