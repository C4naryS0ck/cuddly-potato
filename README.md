# 🔐 Phishing URL Detection using Machine Learning

## 📌 Overview

This project is a Machine Learning-based web application that detects whether a given URL is **phishing** or **legitimate**.

It helps users identify malicious links and avoid cyber attacks like credential theft, fraud, and data breaches.

---

## 🚀 Features

* 🔍 URL classification (Phishing / Legitimate)
* 🤖 Machine Learning model with high accuracy
* 🌐 Simple web interface for user input
* ⚡ Fast prediction response
* 📊 Feature extraction from URLs

---

## 🛠️ Tech Stack

* **Programming Language:** Python
* **Libraries:** Scikit-learn, Pandas, NumPy
* **Web Framework:** Flask
* **Frontend:** HTML, CSS

## ⚙️ Installation & Setup

### 1. Clone the repository

```
git clone https://github.com/your-username/Pishing-URL-Detector.git
cd Pishing-URL-Detector
```

### 2. Create virtual environment

```
python -m venv .venv
.venv\Scripts\activate   # Windows
```

### 3. Install dependencies

```
pip install -r requirements.txt
```

### 4. Run the application

```
python app.py
```
